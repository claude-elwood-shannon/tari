# Tari Ledger Wallet Testing Framework

This directory contains the testing framework for the Minotari Ledger Wallet application using Ledger's Speculos emulator and Ragger testing framework.

## Overview

The testing framework provides comprehensive testing capabilities for the Tari Ledger Wallet application, including APDU command validation, session persistence, and functional testing on Ledger devices.

## Test Files

### Primary Test Scripts

- **`test_tari_ledger_wallet.py`** - Main test script for Tari Ledger Wallet functionality
- **`speculos_experiments.py`** - Experimental script for advanced Speculos testing

### Test Results

- **`tari_ledger_wallet_test.log`** - Log file generated by the main test script
- **`persistent_speculos_debug.log`** - Debug logs from previous test runs

## Prerequisites

### Required Dependencies

```bash
# Install Ragger with Speculos support
pip install 'ragger[speculos]'

# Install Ledger device SDK dependencies
pip install ledgered

# Ensure Rust toolchain is available
rustup default 1.90.0
```

### Ledger Toolchain Setup

```bash
# Install cargo-ledger for Ledger-specific compilation
cargo install cargo-ledger

# Setup Ledger toolchain
cargo ledger setup
```

## Compilation

Before running tests, compile the Tari Ledger Wallet application:

```bash
cd applications/minotari_ledger_wallet/wallet
cargo ledger build flex
```

This will generate the application binary at:
`applications/minotari_ledger_wallet/wallet/target/flex/release/minotari_ledger_wallet`

## Running Tests

### Main Test Script

```bash
# Run the primary test script
cd /data/git/tari
python3 tests/ledger_wallet/test_tari_ledger_wallet.py
```

### Expected Output

The test script will:
1. Start a persistent Speculos session
2. Execute APDU commands in the same session
3. Display decoded responses (app name and version)
4. Validate command execution success

**Sample Output:**
```
✅ Persistent Speculos session started
GetAppName response (decoded): 'minotari_ledger_wallet'
GetVersion response (decoded): '5.1.0-rc.1'
🎉 All persistent tests passed successfully!
```

### Experimental Script

For advanced testing and experimentation:

```bash
python3 tests/ledger_wallet/speculos_experiments.py
```

## APDU Commands Supported

The framework currently supports the following Tari-specific APDU commands:

### Basic Commands
- **`GET_VERSION`** (0x01) - Returns application version
- **`GET_APP_NAME`** (0x02) - Returns application name

### Advanced Commands (Framework Ready)
- `GET_PUBLIC_SPEND_KEY` (0x03)
- `GET_PUBLIC_KEY` (0x04)
- `GET_SCRIPT_SIGNATURE_DERIVED` (0x05)
- `GET_SCRIPT_OFFSET` (0x06)
- `GET_VIEW_KEY` (0x07)
- `GET_DH_SHARED_SECRET` (0x08)
- `GET_RAW_SCHNORR_SIGNATURE` (0x09)
- `GET_SCRIPT_SCHNORR_SIGNATURE` (0x10)
- `GET_ONE_SIDED_METADATA_SIGNATURE` (0x11)
- `GET_SCRIPT_SIGNATURE_MANAGED` (0x12)

## Technical Details

### Session Persistence

The framework uses `SpeculosClient` directly to maintain persistent Speculos sessions, allowing multiple APDU commands to be executed in the same session without restarting the emulator.

### API Level Configuration

The application is compiled with `API_LEVEL=24` for Ledger Flex compatibility, which is correctly detected by Speculos:

```
speculos: Api level detected from metadata: 24
```

### Port Configuration

- **API Port**: 5000 (for Speculos control)
- **APDU Port**: 5001 (for APDU command exchange)

## Troubleshooting

### Common Issues

1. **Application Not Found**
   - Ensure the application is compiled: `cargo ledger build flex`
   - Verify the binary exists at the expected path

2. **Speculos Import Errors**
   - Install Ragger with Speculos support: `pip install 'ragger[speculos]'`
   - Ensure Speculos is properly installed

3. **Session Persistence Issues**
   - The framework uses persistent sessions by default
   - Check that ports 5000 and 5001 are available

### Debug Mode

The test scripts include comprehensive logging. Check the log files for detailed debugging information:

```bash
# View test logs
cat tari_ledger_wallet_test.log

# View debug logs from experiments
cat persistent_speculos_debug.log
```
